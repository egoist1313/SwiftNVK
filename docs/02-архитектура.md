# Архитектура

## Слои кода

```
Команды LISP  НВК-*          оркестратор, DCL, POPER-таблица
       │
       ▼
Nvk.Cad.dll                  трубы, TIN SampleElevation, транзакция erase, redefine блока, NOD
       │
       ▼
Nvk.Core                     стек линий, станции, площади L1–L5  (без AutoCAD, с тестами)
```

## Принципы

1. **Два исходника.** Труба и TIN. Всё остальное — именованные линии, посчитанные один раз.
2. **Домен без графики.** `chain` / `stations` / `geom-cs` не создают примитивов.
3. **Графика ссылается на домен**, не наоборот.
4. **Владение.** Каждый примитив принадлежит участку через NOD-словарь. Не `entlast`, не `ssget "X"`.
5. **Один AppID:** `NVK`.
6. **Реактор отложенный.** `:vlr-modified` только помечает dirty-этапы. Пересчёт на `:vlr-commandEnded`, только dirty + потомки. POPER не трогает EP. EP не трогает CS, если линии не изменились.

## Корень участка (NOD)

Невидимый словарь `NVK_SEGS` / `<seg-id>`:

- config, pipes[], tin, road-zones[]
- именованные линии (см. модель данных)
- stations[], geom-cs[]
- ссылки на INSERT продольников и сечений
- кэш случайных величин (`lat-off`, scatter, цели проб) — пишется один раз при `fresh-build`
