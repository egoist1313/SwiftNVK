# LSP vs DLL vs ARX

| | `.lsp` | .NET DLL | ObjectARX `.arx` |
|---|---|---|---|
| Язык | LISP | C# | C++ |
| Правка | секунды | минуты, сборка | тяжело, SDK на год AutoCAD |
| Civil 3D | COM наугад | `AeccDbMgd` | C++ API |
| Удаление | `entdel` + `entlast` → хвосты | `Transaction` | то же + свой AcDbEntity |
| Уже есть | PipeBuild, POPER | StructSurfacePlugin, TxtPointsImport | ExplodeAllProxy, MTextEditARX |

**LISP** — команды, DCL, оркестратор, POPER, повседневные правки в N++.
**DLL** — трубы, TIN, транзакция erase, redefine блока, NOD.
**ARX не пишем.** Нужен только для своего `AcDbEntity` или взрыва прокси. Блок INSERT это закрывает.

VLX — упаковка LISP, не архитектура. В v1 нет.

Сборки DLL: Civil **2025 / net8** сейчас (как StructSurfacePlugin). 2021 net48 — когда понадобится, тот же `Nvk.Core`.
