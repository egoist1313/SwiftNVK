# Этапы и зависимости

Каждый этап — `nvk-stage-<имя>` + команда `НВК-<имя>`.
`НВК-ПОСТРОИТЬ` гоняет граф. `НВК-ОБНОВИТЬ <этап>` сносит этап и потомков, предков не трогает.

```
[0 CONFIG]
    ▼
[1 INPUT]   трубы + TIN + зоны     ничего не рисует
    ▼
[2 CHAIN]   сортировка, пикетаж
    ├──────────────┐
[3 STATIONS]   [4 SURF]  Z с TIN вдоль оси и по перпендикуляру
    └──────┬───────┘
           ▼
    [5 GEOM-CS]  стек линий + площади L1..L5
           │
   ┌───────┼────────┐
[6 EP]  [7 CS-DRAW]  [8 VOL]
   ▼
[9 POPER]
   ▼
[10 PLAN]
```

| Этап | Нужно | Не нужно |
|---|---|---|
| 5 GEOM-CS | chain, stations, surf, config | продольники, POPER, блоки |
| 7 CS-DRAW | geom-cs + layout + политика блоков | CHILD-полилинии |
| 6 EP | именованные линии (те же, что GEOM-CS) | поперечники |
| 9 POPER | полилинии EP | сечения |
| 8 VOL | площади из geom-cs | нарисованные сечения |
| 10 PLAN | chain, stations, lat-off | сечения |

Поперечник **не ждёт** продольников. Сейчас в старом коде `pc-build-all` выходит, если нет `CHILD:` — это ломаем.
