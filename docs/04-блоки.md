# Политика блоков

Флаг на тип графики: `use-block = yes | no`. Смена флага = этап «перерисовать», домен не пересчитывается.

| Графика | По умолчанию | Зачем |
|---|---|---|
| Поперечник (станция × уровень) | **блок** `NVK-CS-{seg}-{L}-{st}` | Один INSERT, redefine без хвостов |
| Продольник одного типа | **блок** `NVK-EP-{seg}-{type}` | Раздел двигается целиком |
| Таблица POPER | **не блок** | Живые MTEXT / MLEADER / DIM |
| Штриховка сечения | внутри блока сечения | Иначе осиротевший HATCH |
| Метки пикетов | не блок | Липнут к профилю |
| План, выноски проб | не блок | Двигают руками |
| Таблица координат / объёмов | `ACAD_TABLE` | Редактируемая |

Команда `НВК-БЛОКИ` (или галки участка). Режим loose — explode по команде, не внутри движка.
