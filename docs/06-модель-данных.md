# Модель данных: два исходника и стек линий

## Исходники

Ровно два. Больше ничего «с натуры» не читаем.

```
ТРУБА Civil 3D                         ПОВЕРХНОСТЬ TIN
  invert (лоток) начало/конец            Z в точке плана
  diam                                   Z вдоль перпендикуляра к оси
  XY начала/конца
  колодцы (имя, радиус, sump)
```

Из трубы считаем цепочку (`chain`) и пикетаж. Из TIN — отметки земли. Толщины (постель, защита, дорожная одежда) — из config участка, не из чертежа.

## Именованные линии (считаются один раз)

На каждом пикете (и на каждой вершине цепочки):

| Имя | Формула | Смысл |
|---|---|---|
| `TrenchBottom` | `invert − bedding` | дно траншеи |
| `SandTop` | `invert` | верх песка = лоток трубы |
| `PipeTop` | `invert + diam` | верх трубы |
| `ZashTop` | `invert + diam + thk_zash` | верх защитного слоя |
| `Surface` | TIN − толщина одежды в зоне | подошва покрытия / земля |

Это **одни и те же числа** для продольника и для поперечника. Не пересчитывать «ещё раз чуть иначе» в `pb-build-pesok` / `pc-section-geom`.

## Нижняя линия переезжает в следующий профиль

Штриховка каждого продольника — полигон «нижняя линия + верхняя линия». Нижняя **не считается заново**, а берётся из предыдущего слоя.

```
Surface ────────────────────────────────────────  TIN
         L5  обратная засыпка
ZashTop  ───────────────────────────────────────  верх защиты
         L4  защитный слой
SandTop  ───────────────────────────────────────  верх песка = лоток = НИЗ ЗАЩИТЫ
         L2  песок (постель)
TrenchBottom ───────────────────────────────────  дно траншеи
         L1  разработка: от дна до Surface

Труба (L3) сидит между SandTop и PipeTop.
```

| Продольник | Нижняя (переехала) | Верхняя |
|---|---|---|
| Разработка | `TrenchBottom` | `Surface` |
| Песок | `TrenchBottom` **та же** | `SandTop` |
| Труба | `SandTop` (лоток) | `PipeTop` |
| Защита | `SandTop` **та же, что верх песка** | `ZashTop` |
| Засыпка | `ZashTop` **та же, что верх защиты** | `Surface` |

Следствия:

- Поменяли `bedding` → меняется только `TrenchBottom` → перерисовываются разработка и песок. Защита не трогается.
- Поменяли `thk_zash` → меняется `ZashTop` → защита и засыпка. Песок не трогается.
- Подвинули трубу → все пять линий, потому что все от `invert`/`diam`.
- Подвинули TIN → только `Surface` → разработка и засыпка.

Поперечники L1…L5 — те же пары линий в плоскости сечения, не «ещё одна геометрия».

## Площади / объёмы

Площадь уровня = полигон нижней и верхней линии (с вырезом трубы там, где он нужен). Не из штриховки чертежа. Объём = Σ (площадь_прод × ширина_траншеи_по_диаметру), как сейчас в `pb-vt-*`, но от `geom-cs`, не от найденных HATCH.

Особые правила (из июля 2026, оставляем):

- `Surface` не ниже `TrenchBottom`.
- L5 (засыпка) существует только если `Surface > ZashTop`, иначе площадь 0 и не рисуем.
- ASPH: если `ZashTop` заходит в песок одежды — серая зона не входит в объём защиты.

## Стык → ширина дна

Как `pc-trench-width`: SOCKET / WELD / COUPLING, пороги 0.5 м и 1.6 м. Минимум 0.7 м.

## Случайные величины

`lat-off`, scatter, цели проб — в корне участка, один раз при `fresh-build`. Реактор их не перекатывает.
