## G — оркестратор  (этот заход)

`НВК-ПОСТРОИТЬ` / `НВК-ОБНОВИТЬ` — полный прогон, точки вставки помнит.
`НВК-ОЧИСТИТЬ` — транзакция, только графика NVK-* и блоки NVK-CS/EP. Трубы и TIN не трогает.
`НВК-СБРОС` — забыть точки вставки.

Реактор на лету не включаем: пересчёт — явная команда, без флажков `*poper-updating*`.

## После G — настройки и память чертежа

`НВК-НАСТРОЙКИ` — DCL: постель, защита, стык, откос, масштабы, станции.
Состояние (трубы, TIN, точки, настройки) пишется в NOD `NVK` и поднимается при `(load)`.

Документы. `nvk-load.lsp`, слои, AppID, оркестратор-заглушка, `НВК-ИНФО`.
`Nvk.Core` — стек линий + ширина траншеи + тесты.
`Nvk.Cad.2025` — `NVK-PING`, чтение одной трубы.

## B — домен без графики

INPUT + CHAIN + STATIONS + SURF + GEOM-CS.
`НВК-ДАМП` печатает станции и отметки. Ни одной линии в чертеже.
Сверка с `pc-section-geom` на эталонном dwg.

## C — поперечник как блок

Один INSERT на сечение. Удаление = erase INSERT.
`НВК-СЕЧЕНИЯ`. Сравнение с текущим `ТРУБСЕЧЕНИЯ`.

## D — продольники блоками

Те же именованные линии. Loose-режим флагом. Без POPER. `НВК-ПРОФИЛЬ`.

## E — POPER

Нарезка таблицы, реактор только на подписи.

## F — план + объёмы

Из домена, не из «что нарисовали».

## G — оркестратор

`НВК-ПОСТРОИТЬ` с галками этапов и блоков. Deferred reactor. `НВК-ОЧИСТИТЬ` сносит только свой словарь.

Импорта старых PIPEBLD нет.

## Готово, когда

- Повторный `НВК-СЕЧЕНИЯ`: число объектов NVK не растёт.
- Выключили EP — CS жив.
- Выключили блок — те же координаты.
- Ctrl+C не оставляет полутрупы.
- Правка EP не сносит поперечники.
- Два участка не делят глобальный X.
