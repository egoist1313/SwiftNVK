# Поперечник НВК

Камералка наружных сетей ВК в Civil 3D: продольники, поперечники, таблица отметок, план, объёмы.

Старые `PipeBuild_merged1.lsp` и `PoperSwift.lsp` **не трогаем**. Это новый проект.

## Как грузить

1. Собрать DLL (один раз, Civil 2025):

```
dotnet build "src\csharp\Nvk.sln" -c Release
```

2. В AutoCAD / Civil 3D:

```
NETLOAD  →  src\csharp\Nvk.Cad.2025\bin\Release\net8.0-windows\Nvk.Cad.dll
(load "E:/Новая папка/Lich15/Поперечник НВК/src/lisp/nvk-load.lsp")
```

Или одной командой: загрузить только `nvk-load.lsp` — он сам попытается `NETLOAD`.

3. `НВК-ИНФО` → `НВК-НАСТРОЙКИ` → `НВК-ПОСТРОИТЬ`. Снос графики: `НВК-ОЧИСТИТЬ`.
   Состояние участка живёт в чертеже (NOD `NVK`): после нового `(load)` трубы, TIN и точки вставки подхватятся.

## Решения

| | |
|---|---|
| Объём | Весь конвейер, этапы раздельно |
| Старые dwg | Чистый старт, без импорта PIPEBLD |
| Формат | LISP + .NET DLL. Не ARX, не VLX |
| Блоки | Сечение = блок, продольник = блок, таблица POPER = не блок |

## Два исходника

Единственные входы: **труба Civil 3D** и **поверхность TIN**. Все линии слоёв считаются из них один раз и **переезжают** в следующий профиль / уровень сечения. См. `docs/06-модель-данных.md`.
