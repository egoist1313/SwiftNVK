## Настройки и память

```
НВК-НАСТРОЙКИ     ; постель 0.15, стык WELD, OK
НВК-ПОСТРОИТЬ
```

Сохрани dwg, новый сеанс, `(load nvk-load.lsp)` — в инфо те же трубы/TIN/точки. `НВК-ОБНОВИТЬ` без повторного выбора.

## G — оркестратор

```
НВК-ПОСТРОИТЬ     ; первый раз спросит точку CS
НВК-ОБНОВИТЬ      ; те же точки, те же трубы
НВК-ОЧИСТИТЬ      ; графика NVK исчезла, трубы на месте
НВК-ПОСТРОИТЬ     ; рисует снова в те же точки
НВК-СБРОС         ; следующий прогон снова спросит точку
```

Хвостов после ОЧИСТИТЬ + ПОСТРОИТЬ быть не должно.

## F — объёмы и план

После перезапуска `НВК-ПОСТРОИТЬ`:

- слой `NVK-VOL` — MTEXT с объёмами L1/L2/L4/L5 по диаметрам (из домена, не из штриховки)
- слой `NVK-PLAN` — ось труб, контур траншеи, кружки станций, колодцы (в мировых XY трассы)

Отдельно: `НВК-ОБЪЁМЫ`, `НВК-ПЛАН`.

## E — таблица подписей

После перезапуска:

```
НВК-ПОСТРОИТЬ
```

Под каждым продольником — таблица на слое `NVK-POPER`: отметки на стыках, длины, уклоны ‰.
Не блок. Повторный прогон стирает старые подписи слоя, не плодит хвосты.
Только таблица: `НВК-ПОДПИСИ` (нужны уже построенные EP).

## D — продольники

После перезапуска Civil:

```
НВК-ПОСТРОИТЬ
```

В логе `EP` = OK, на чертеже 5 блоков `NVK-EP-*` столбиком: разработка / песок / труба / защита / засыпка.
Нижняя линия каждого = верхняя (или та же нижняя) предыдущего.
Только продольники: `НВК-ПРОФИЛЬ`.

## C — поперечники + полный прогон

**Перезапусти AutoCAD** (новая DLL). Затем:

```
(load "E:/Новая папка/Lich15/Поперечник НВК/src/lisp/nvk-load.lsp")
НВК-ПОСТРОИТЬ
```

Выбери трубы (если ещё нет), укажи точку вставки сечений в пустом месте.

В логе: каждый этап `OK` / `SKIP` / `FAIL`. На чертеже — блоки `NVK-CS-*` (колонки = станции, ряды = L1…L5).

Повторный `НВК-ПОСТРОИТЬ` не должен плодить хвосты: старые INSERT того же префикса стираются.

## B — домен без графики

```
НВК-ДАМП
```

Выбрать трубы (и TIN, если их несколько). В командную строку — длина цепочки, группы диаметров, станции AUTO, стек линий.

Проверить:

- дно разработки = дно песка (`TrenchBottom`)
- верх песка = низ защиты (`SandTop`)
- верх защиты = низ засыпки (`ZashTop`)
- L5засып=`нет`, если поверхность не выше защиты
- в чертеже **не появилось** ни одной новой линии
- повторный `НВК-ДАМП` снова только текст
